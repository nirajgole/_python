### Big O Notation

> how running TIME or SPACE requirements for your program grows as input size grows. <br/>
time = a*n + b <br/>
keep fastest growing term  time = a*n <br/>
remove constant time = O(n) -> order of n <br/>
generally we take worst case scenario while calculating Big O
